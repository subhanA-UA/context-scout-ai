# Contributing

Thanks for helping improve Context Scout AI.

## Ground Rules

- Keep changes focused and easy to review.
- Add tests for behavior changes.
- Update documentation when commands, configuration, or public APIs change.
- Do not paste code copied from incompatible licenses.

## Local Development

```bash
npm install
npm test
```

## Pull Requests

Open a pull request with:

- A short summary of the change
- Screenshots or terminal output when CLI behavior changes
- Notes about tests run
